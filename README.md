# Science Tools

A static reference page with constants, formulas, and calculators for chemistry, spectroscopy, classical mechanics, electromagnetism, atomic physics, quantum physics, and trigonometry.

Open [conversions.html](conversions.html) in a browser. No build step or backend is required. Calculators work offline; MathJax typesetting requires an internet connection.

- [Project documentation](PROJECT.md): setup, behavior, scientific conventions, and implementation.
- [Disciplines](DISCIPLINES.md): subject scopes, content assignments, and references.
- [CODATA reference](allascii.txt): NIST 2022 constants listing.
