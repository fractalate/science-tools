A note on precision

Same constant. Different units.

Changing units changes the displayed value, not the physical quantity. Values marked “exact” are defined in SI; converted displays may be rounded.

Constants with standard uncertainties are measured values. Their standard uncertainties are shown below the value. Standard gravity is an exact reference value; local gravity varies. Values use scientific notation, with exponent 1 displayed as exponent 0.
